# 📊 Data Management for Business Intelligence

Welcome to this repository containing projects focused on **data management techniques for business intelligence solutions**. This collection demonstrates how to design, structure, and manage data systems for analytics and reporting — from operational databases to analytical data warehouses.

---

## 📂 Projects Overview

### 📁 Project 1: Relational Database Design (3NF)

- **Objective:**  
  Design and implement a **relational database** following **Third Normal Form (3NF)** to support efficient transaction processing and data integrity.

- **Tools Used:**  
  - **MySQL Workbench** (for schema design and SQL implementation)  
  - **Microsoft Excel** (for data modeling and relationship mapping)

- **Key Activities:**  
  - Develop an Entity-Relationship Diagram (ERD)
  - Normalize data structures up to 3NF
  - Implement relational tables, primary and foreign key constraints
  - Populate and query the database

---

### 📁 Project 2: Data Warehouse Design & ETL Pipeline

- **Objective:**  
  Build a **data warehouse environment** to support business intelligence reporting and dashboards, integrating data from multiple sources through an ETL process.

- **Tools Used:**  
  - **Python** (for data processing scripts)
  - **Alteryx** and **Tableau Prep** (for ETL workflows)
  - **MySQL** (for data warehouse schema and storage)
  - **Power BI** (for creating visual dashboards and reports)

- **Key Activities:**  
  - Design dimensional models and star schemas
  - Build ETL pipelines for data extraction, transformation, and loading
  - Implement fact and dimension tables in MySQL
  - Create interactive dashboards and performance reports in Power BI
